# Bazar Dor — বাজার দর

Bangladesh grocery price tracking website built with Next.js.

## Features
- Browse grocery products and current prices.
- Explore eight grocery categories.
- View product details and market-wise prices.
- Sort products by price.
- Track rising and falling prices.
- Bengali date and scrolling price ticker.
- Email and password authentication.
- Protected user profile.
- Update profile name.
- Responsive navigation and loading states.

## Technologies
- Next.js
- React
- TypeScript
- Tailwind CSS
- Better Auth
- SQLite
- Lucide React
- React Hot Toast

## API
https://openapi.programming-hero.com/api/bazardor

## Installation
1. Run npm install
2. Configure the environment variables in .env.local
3. Run npm run dev
4. Open http://localhost:3000

## Production Build
npm run build
